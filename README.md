# Home_Sales

## Summary
Using the Home_Sales_Colab notebook within Google Colab, I utilized SparkSQL to demonstrate the use of big data to create temporary dataframe views. Which were then utilized for the statistical calculations such as the average price for a four bedroom house sold per year, and average price price of a home for each year the home was built. After calculating a couple more statistical queries, I 'cached' the temporary table created at the beginning, to re-run the original query to see if there is a faster procesing time, which it did and continued to do so as I progressed. The last thing I executed was implimenting the parquet method to re-run the original query before uncaching the temporary home_sales table.
